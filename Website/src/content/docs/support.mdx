## Report a bug

Bug reports are managed with the [GitHub issues](https://github.com/Ircam-Partiels/Partiels/issues) of the project (a free GitHub account is required). Before creating a new issue, please check that the problem persists with the [latest version](../download/) and that it has not already been reported.

To help us reproduce and fix the problem, please describe:

- the version of Partiels and of the plugins concerned,
- your operating system and its version (and the processor for macOS: Apple Silicon or Intel),
- the steps to reproduce the problem, what you expected and what happened,
- screenshots or a screen recording if relevant.

:::tip
If the problem concerns a specific document, attach a [consolidated version](../manual/#32-save-and-consolidate) of the document: it contains the audio files and the analysis results so that we can open it on another machine.
:::

## Suggest a feature

Feature requests can be created as [issues](https://github.com/Ircam-Partiels/Partiels/issues/new?template=feature_request.yml) or discussed first in the [Ideas discussions](https://github.com/orgs/Ircam-Partiels/discussions/categories/ideas).

## Stay informed

New versions are announced in the [Announcements discussions](https://github.com/orgs/Ircam-Partiels/discussions/categories/announcements). You can also be notified of new releases by watching the [GitHub repository](https://github.com/Ircam-Partiels/Partiels) (Watch → Custom → Releases).

## Contribute

- **Translations**: Partiels is available in several languages, and you can improve or add a translation as explained in the [manual](../manual/#16-translations).
- **Show and tell**: share your use of Partiels in the [Show and tell discussions](https://github.com/orgs/Ircam-Partiels/discussions/categories/show-and-tell).
- **Code**: the source code is available on [GitHub](https://github.com/Ircam-Partiels/Partiels), and contributions are welcome.
