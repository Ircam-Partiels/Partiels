Partiels uses the [Vamp plugin technology](https://www.vamp-plugins.org/), an audio processing plugin system developed at the Centre for Digital Music, Queen Mary, University of London, to extract descriptive information from audio data.

Alongside Partiels, a wide range of analyses based on audio engines developed at IRCAM and elsewhere are ported to Vamp plugins.

## Basic Pitch

The [Basic Pitch plugin](https://github.com/Ircam-Partiels/basic-pitch-vamp-plugin) ports [Basic Pitch](https://github.com/spotify/basic-pitch), the automatic music transcription library developed by [Spotify's Audio Intelligence Lab](https://research.atspotify.com/audio-intelligence/), to Vamp. Its lightweight neural network is embedded in the plugin and detects the notes of polyphonic recordings. The plugin is included in the full bundle and can also be installed individually from the list above (on macOS, it requires macOS 13.3 or later and an Apple Silicon processor).

The notes are split into monophonic voices ordered from the lowest to the highest, and each voice is returned by a dedicated output: in Partiels, a track is created for each voice, and the tracks share the same analysis and parameters. The pitch of each note is returned as a curve in Hertz, with the amplitude of the note associated with each result, so you can filter the notes according to a threshold.

The analysis is controlled by the following parameters:

- **Frame Threshold** (0.05 to 0.95, 0.3 by default): the amplitude threshold of the frames.
- **Onset Threshold** (0.05 to 0.95, 0.5 by default): the amplitude threshold of the onsets.
- **Minimum Note Duration** (0 to 1000 ms, 128 ms by default): the minimum duration of the notes.
- **Number of Voices** (1 to 24, 4 by default): the number of monophonic voices, and therefore of outputs and tracks.

## Installation

The installers copy the plugins to the default Vamp folder of your system, where Partiels finds them at startup:

- **macOS**: `/Library/Audio/Plug-Ins/Vamp`. Plugins that require a more recent version of macOS or an Apple Silicon processor are only offered when they are compatible with your Mac.
- **Windows**: `C:\Program Files\Vamp Plugins`. The plugins can be uninstalled individually from the Windows settings.
- **Linux**: `$HOME/vamp`. Run the `Install.sh` script of the archive (with the `--all` option to install all the plugins), and the `Uninstall.sh` script to remove them.

You can change the folders in which Partiels looks for plugins in the [plugins settings](../manual/#13-plugins-settings).

:::caution
Some Vamp plugins may not support all the configurations and may have other restrictions.
:::
